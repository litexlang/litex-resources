# litex-resources

This directory collects reference materials related to Litex, helping human authors and AI understand, write, and maintain Litex code more effectively.

## Contents

- [`examples/`](examples/): Runnable examples and focused examples covering syntax, proof nodes, module management, inference, and well-definedness behavior.
- [`docs/`](docs/): Usage guides, developer documentation, and workflow references for Litex.
- [`showcases/`](showcases/): Larger Litex projects organized around complete topics or mathematical areas, showing how Litex can be used in broader settings.

## How to Use

If you are new to Litex, start with the smallest example in `examples/` that is closest to your problem, then consult `docs/` for commands and conventions. For complete mathematical models or longer proofs, explore `showcases/`.

These materials are intended both for human readers and as context and examples for AI systems writing Litex. When using an example, check its local README, version information, and whether it is still covered by the repository's verification workflow.
